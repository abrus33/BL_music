# 沉浸式个人音乐库界面改版设计

日期：2026-07-13
状态：已完成对话确认，等待书面审阅

## 1. 背景与目标

当前项目已经具备首页、收藏夹、登录、播放控制和播放队列等核心能力，但页面在元素排布、视觉层级、图标一致性和动态反馈上仍偏原型化。收藏夹页面虽然维护了 `folders` 与 `resources` 两种状态，却使用两个 `Repeater` 的 `visible` 属性尝试切换视图；这不适合作为互斥页面容器，实际会出现收藏夹内容继续排在收藏夹列表下方的问题。

本次改版的目标是建立一套可持续迭代的全局设计系统和应用框架，再分批迁移全部现有页面。最终界面应呈现“沉浸式个人音乐库”的体验：深色、克制、安静，突出封面、媒体内容和正在播放状态，B 站粉只用于关键操作和状态反馈。

## 2. 范围

本次设计覆盖：

- 全局主题、语义令牌、间距、圆角、控件尺寸和动效规范；
- 主窗口骨架、页面容器、响应式侧栏和全局浮层；
- 收藏夹总览与收藏夹详情的独立视图；
- 首页、登录页、底部播放器和播放队列；
- 现有 SVG 图标的资源化、规范化和缺失图标补充；
- 加载、空数据、错误、重试、禁用和键盘焦点等完整状态；
- 面向窗口缩放、后续页面增加和数据模型升级的组件边界。

本次不改变认证、网络、媒体解析和播放核心业务的职责，不进行与界面改版无关的 C++ 大规模重构。

## 3. 视觉方向

### 3.1 产品语义

- 领域：夜间聆听、私人收藏、唱片架、正在播放、播放队列、轻量探索；
- 色彩世界：石墨黑、炭灰、柔和白、雾灰、封面原色和少量 B 站粉；
- 标志性元素：当前播放项使用克制的粉色“播放轨迹”，从媒体列表选中状态延续到底部播放器；
- 深度策略：以低对比表面色阶和轻边界为主，不混用夸张阴影与强分割线；
- 信息层级：标题、主要内容、辅助信息和禁用信息形成四级文字层级。

### 3.2 明确舍弃

- 不使用 Emoji 充当导航或播放控制图标；
- 不使用大面积粉色、装饰性渐变或夸张投影；
- 不让全部卡片、文字和操作拥有同等视觉权重；
- 不在页面中散落随机颜色、尺寸、圆角和动画时长；
- 不依赖绝对文件路径加载图标。

## 4. 全局应用框架

`Main.qml` 只负责组合应用骨架：导航区、页面区、播放器区和全局浮层。页面业务状态由各页面或页面级控制器管理。

应用框架包含：

- `AppShell`：主布局和响应式断点；
- `NavigationRail`：完整侧栏与折叠图标栏；
- 页面容器：使用真正的互斥视图或路由状态，不依赖 `Repeater.visible` 切页；
- `PlayerBar`：媒体信息、核心控制、进度和辅助控制四个可收缩区域；
- `QueueDrawer`：从右侧进入的播放队列面板；
- 全局浮层：错误提示、轻量通知和后续弹层的统一挂载点。

### 4.1 响应式规则

- 宽屏（`>= 1180px`）：完整侧栏、完整播放器和受控的内容最大宽度；
- 中等宽度（`860px` 至 `1179px`）：侧栏折叠为图标栏，播放器隐藏次要状态和部分文字；
- 紧凑宽度（`< 860px`）：保留返回、播放/暂停、进度和队列入口，隐藏非核心辅助控件；
- 推荐展示尺寸为 `1360x860`，同时设置不会导致核心操作重叠的合理最小窗口尺寸；
- 窗口缩放通过布局状态切换完成，不对宽高和边距做连续动画。

## 5. 收藏夹体验

### 5.1 导航模型

收藏夹页面由两个真正互斥的视图组成：

```text
收藏夹总览 -> 点击收藏夹 -> 收藏夹详情
收藏夹详情 -> 点击返回 -> 收藏夹总览
```

进入详情后，总览视图不参与当前布局；详情页只展示当前收藏夹的标题、返回操作、状态和视频列表。返回总览不会中断当前播放，并恢复总览原有滚动位置。

### 5.2 收藏夹总览

- 展示页面标题、收藏夹数量、刷新入口和收藏夹卡片；
- 收藏夹卡片展示名称、内容数量、可用辅助信息和进入箭头；
- 宽屏可采用两列，窄屏自动切为单列；
- 未登录、加载、空数据和加载失败均使用独立状态组件。

### 5.3 收藏夹详情

- 顶部展示返回按钮、收藏夹名称、视频数量和可扩展操作区；
- 视频列表展示封面、标题、UP 主、时长、资源类型和失效状态；
- 点击有效视频后，以当前项为起点创建完整播放队列；
- 失效资源保持可见但不可播放，并解释原因；
- 当前播放项显示粉色播放轨迹、播放图标和轻微背景差异；
- 再次打开已加载的收藏夹时可优先展示缓存，并在后台刷新。

### 5.4 页面状态

收藏夹页面使用明确状态：

- `foldersLoading`
- `foldersReady`
- `folderLoading`
- `folderReady`
- `empty`
- `error`

切换收藏夹时先更新目标收藏夹标识，再接收异步结果。异步结果必须与当前目标相符，防止快速点击时旧请求覆盖新页面。失败时保留标题栏和返回能力，并提供重试操作。

首阶段继续兼容现有 `FavoriteService` 的 JSON 字符串信号。页面适配层负责解析和状态归属，展示组件不直接访问服务。后续替换为 `QAbstractListModel` 时，不改变视觉组件接口。

## 6. 组件体系

建议建立以下边界：

- `PageHeader`：页面标题、返回、说明和操作插槽；
- `Icon` / `IconButton`：图标资源、尺寸和交互状态；
- `FolderCard`：收藏夹摘要展示并发出 `folderOpened(id)`；
- `MediaList` / `MediaListItem`：共用媒体列表展示并发出 `mediaActivated(id)`；
- `EmptyState`、`ErrorState`、`SkeletonList`：异步内容状态；
- `PlayerBar`：组合播放器的响应式子区域；
- `QueueDrawer`：播放队列展示与操作；
- `Theme`：语义颜色、文字层级、间距、圆角、尺寸、断点和动画时长。

通用组件只接收展示数据并发出语义事件，不直接调用 `applicationContext`。页面负责连接组件事件与 C++ 服务。

## 7. 图标系统

- 将 `icon` 目录中的 SVG 纳入 Qt 资源系统；
- 以稳定的语义名称建立图标清单，例如 `home`、`chevron-left`、`search`；
- 补充许可清晰、视觉风格一致的收藏夹、播放、暂停、上一首、下一首、音量、队列、循环和随机图标；
- 统一图标的 `viewBox`、视觉尺寸、线宽或填充策略；
- 通过 `Icon` 与 `IconButton` 控制默认、悬停、按下、焦点、禁用和选中状态；
- 固定灰色填充的现有 SVG 应在资源层统一规范化，不复制多套页面专用文件。

## 8. 动效规范

- 悬停与选中反馈：`120-160ms`；
- 页面内容切换：`180-220ms`，仅使用透明度和轻微位移；
- 队列面板进入：`220-260ms`；
- 按钮按下：轻微缩放，不低于 `0.95`；
- 首次加载列表可短促分批淡入，频繁刷新不重复播放入场动画；
- 动画只操作 `opacity` 和 `transform`，不使用 `transition: all`；
- 提供 `reduceMotion` 配置，启用时去除位移和缩放，仅保留必要颜色反馈。

## 9. 数据流与职责

- C++ 服务层负责认证、网络、收藏夹加载、媒体解析、播放控制和队列；
- 页面级 QML 负责加载、就绪、空数据、错误和当前目标等编排状态；
- 通用 QML 组件只负责展示和语义事件；
- 页面导航状态与播放器状态相互独立；
- JSON 到 QML 模型的兼容逻辑集中在页面适配层，避免进入视觉组件；
- 后续新增搜索、历史记录或下载页面时复用 `PageHeader`、`MediaList` 和状态组件。

## 10. 页面迁移顺序

1. 全局设计令牌、图标系统和基础状态组件；
2. `Main.qml` 应用框架、响应式侧栏和页面容器；
3. 收藏夹总览与详情，优先修复互斥显示；
4. 底部播放器与右侧播放队列；
5. 首页推荐视图；
6. 登录页的登录状态、扫码流程和错误反馈；
7. 全局交互状态、窗口缩放和视觉一致性收尾。

## 11. 错误处理与可访问性

- 所有异步区域提供加载、空、错误和重试状态；
- 快速切换收藏夹或退出登录时，旧结果不得污染新状态；
- 所有可点击元素使用语义化 Qt Quick Controls 或完整键盘交互；
- 所有按钮具备默认、悬停、按下、焦点、禁用和选中状态；
- 核心点击区域不小于 `40x40px`，优先达到 `44x44px`；
- 失效媒体不静默失败，列表中明确标记且播放入口禁用；
- 减少动态设置不影响状态可辨识性。

## 12. 验收标准

- 点击收藏夹后只显示该收藏夹的视频列表；返回后只显示收藏夹总览；
- 快速切换、空收藏夹、加载失败和退出登录不会留下上一请求的内容；
- 在 `1360x860`、约 `1024x700` 和最小窗口三档完成布局检查；
- SVG 从打包资源加载，发布运行不依赖本机绝对路径；
- 全部交互控件具有完整状态，全部异步区域具有加载、空、错误和重试状态；
- 动效不阻塞连续操作，并响应减少动态设置；
- CMake 配置、构建和现有测试通过；
- 增加收藏夹互斥视图和异步结果归属的 Qt Quick 测试；
- 完成实际窗口缩放及逐页视觉检查，确认无重叠、裁切、空白或不可读状态。

## 13. 非目标

- 不在本轮增加搜索、历史记录、歌词或下载等新业务能力；
- 不重写已经工作的认证、网络或播放器核心链路；
- 不为了视觉改版一次性把全部 JSON 通信替换为 C++ 模型；
- 不引入与 Qt/QML 现有技术栈不一致的 UI 框架。
